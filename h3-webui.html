系統設定

改完即時保存，重新整理不會消失。

連線與生成

temperature / top_p 等取樣參數請在 llama-server 後台（.env / 啟動參數）設定，前端只需要位址。

llama-server 位址設定在伺服器端的 config.json（llama_url），改檔存檔即生效；網頁不顯示、也不需填寫。

生成結果不符合重試目標時自動重新生成，直到符合或用完次數， 並保留其中最好的一次。設 0 關閉。

🎞️ 進階：硬切檢測與自動重試

影片生成完後自動品質審查（混合架構：ffmpeg 場景偵測抓硬切候選 → 視覺模型看幀確認並判斷劇情符合度）。 不通過會自動「換 seed 重跑」或「修劇情重跑」，直到通過或用完重試次數（保留評分最高的一次）。 只有勾選的類型會啟用。

📚 經驗庫（整理經驗）

你在歷史紀錄上的 👍👎／標籤／備註會累積在這裡。按「整理經驗」讓模型一次歸納全部待整理的反饋， 提出通用規則；你審核後入庫，之後每次生成都會注入（依模式）。建議累積約 5 筆再整理，規則會準得多。

生成影片 System Prompt（全部類型）

I2VA / FL2VA / L2VA / REF2VA 四種模式共用同一份生成用 system prompt——內建版本已涵蓋四種模式的格式規則。 左邊勾選哪一組，產生時就用哪一組。編輯內容會自動保存到伺服器。

評分審查影片 System Prompt

「硬切檢測與自動重試」的視覺審查員指令——審查影片時帶入，定義評分規則與 accept / reroll / revise 的決策。 修改時務必保留「只輸出 JSON」的要求與欄位格式，否則審查結果無法解析。編輯即自動保存（存於本機瀏覽器）。

刪除上傳圖片

「只從庫移除」不會動到任何歷史紀錄——每筆紀錄都保有自己的原圖，之後照樣能點開、重跑； 如果日後再上傳同一張圖，這些紀錄會自動重新掛回來。
